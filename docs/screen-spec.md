# 画面仕様

## 1. 結論

このリポジトリはJavaクライアントライブラリであり、画面、URL route、View、Component、Template、静的Web資産を実装していない。そのため画面一覧および画面固有仕様は「該当なし」である。

## 2. 画面一覧

| URL / route | 目的 | 表示・入力・操作 | 関連View / Component / Template |
|---|---|---|---|
| 該当なし | 本リポジトリはUIを提供しない | 該当なし | 該当なし |

## 3. 状態別表示

通常、ローディング、データなし、エラー、権限なしの表示は、本ライブラリを利用するアプリケーションの責務である。本ライブラリは `NobyClient.exec` を同期実行し、成功時に `Result`、失敗時に例外を返すのみである。

利用側で少なくとも次を定義する必要があるが、本書では文言や挙動を確定しない。

- 通信中の表示とキャンセル可否
- 正常な `Result` の表示方法
- 空または一部欠落した結果の表示
- HTTP 400等の入力・要求エラー表示
- 認証・権限エラー表示
- 429・5xx・タイムアウト等の一時障害表示と再試行
- 会話文、位置情報、認証情報を画面・ログへ露出しない扱い

## 4. 使用API

画面から直接使用するAPIはない。利用側アプリケーションが本ライブラリを介して外部NOBY APIを使用する場合は [api-spec.md](api-spec.md) を参照する。
